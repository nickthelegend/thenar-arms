# Thenar robot studio

An engineering viewer for the workspace owner's MG996R follower and magnetic-encoder leader. The user explicitly asked to build both robots, inspect the actual 3D assemblies in a website, verify the design, export printable components and arrange them efficiently for a Bambu P1S. Success means rotating actual exported meshes, exercising matching joint poses, inspecting purchased components separately from printable parts, and downloading CAD and arranged plates. The current prototype is physically untested; reports must distinguish geometric checks from physical fit and motion validation. No hardware control is exposed in the website. Chosen implementation assumptions: daylight engineering workspace, desktop-first with responsive mobile controls, local CAD exports as authoritative assets, dark blue structure and amber follower parts with blue leader parts. These choices implement the user's request to proceed end to end.
